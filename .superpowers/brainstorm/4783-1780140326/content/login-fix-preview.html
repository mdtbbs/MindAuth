登录页面 (#login) 白屏问题修复

分析原因：模板元素设置了 opacity:0 作为动画初始状态，但动画未正确触发

问题诊断
模板 HTML 中的初始状态
<div class="login-brand" style="opacity:0; transform:translateX(-50px)"> <div class="login-form" style="opacity:0; transform:translateX(50px)">
❌ 结果：页面元素不可见
元素保持在 opacity:0 状态，用户看到的是白屏
修复方案
✅ CSS 动画触发
.login-brand { animation: login-brand-enter 0.6s ease-out forwards; } @keyframes login-brand-enter { from { opacity:0; transform:translateX(-50px); } to { opacity:1; transform:translateX(0); } }
关键：animation-fill-mode: forwards 让动画结束后保持最终状态
动画时序设计
品牌区 0.6s
→
表单 0.1s延迟
→
内容 0.3s延迟
stagger delay 实现依次入场效果，视觉层次分明
