MindAuth

OAuth 2.0 接入文档

第三方应用接入指南

接入流程

MindAuth 使用标准 OAuth 2.0 授权码模式：

1. 用户点击第三方应用的「登录」按钮
2. 重定向到 /authorize 端点
3. 用户登录并授权（已登录则自动授权）
4. 重定向回第三方应用，携带 code
5. 第三方后端用 code 换取 access_token

API 端点

GET /authorize

授权端点，用户浏览器重定向到此URL发起授权请求

参数必需说明
client_id是应用客户端ID
redirect_uri是回调地址，必须与管理后台配置一致
state推荐防CSRF攻击，原样返回
scope可选权限范围

成功：重定向到 redirect_uri?code=xxx&state=xxx

失败：重定向到错误页面

POST /token

Token交换端点，后端用授权码换取访问令牌

参数必需说明
code是授权码，5分钟内有效
client_id是应用客户端ID
client_secret是应用密钥

返回：access_token, refresh_token, expires_in, user

POST /refresh

刷新令牌端点，获取新的访问令牌

参数必需说明
refresh_token是刷新令牌
client_id是应用客户端ID
client_secret是应用密钥

返回：access_token, expires_in, user

POST /verify

Session验证端点（同域场景）

参数必需说明
session_token是用户会话Token

返回：user 信息

示例代码

JavaScript (发起授权)

// 构建授权URL并重定向
const authUrl = `/authorize?client_id=${clientId}&redirect_uri=${redirectUri}&state=${state}`;
window.location.href = authUrl;

JavaScript (Token交换)

// 回调页面获取code后，后端交换token
const response = await fetch('/token', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    code: authCode,
    client_id: 'your_client_id',
    client_secret: 'your_client_secret'
  })
});
const data = await response.json();
// data.access_token, data.refresh_token, data.user

Python (Token交换)

import requests

response = requests.post('/token', json={
    'code': auth_code,
    'client_id': 'your_client_id',
    'client_secret': 'your_client_secret'
})
data = response.json()
# data['access_token'], data['refresh_token'], data['user']

返回数据格式

Token响应

{
  "success": true,
  "access_token": "xxx",
  "refresh_token": "xxx",
  "expires_in": 3600,
  "user": {
    "id": 1,
    "username": "user_name",
    "email": "user@example.com",
    "created_at": "2024-01-01"
  }
}

错误响应

{
  "error": "invalid_grant",
  "error_description": "授权码无效或已过期"
}

注意事项

• 授权码有效期为 5 分钟，且只能使用一次

• access_token 有效期为 1 小时

• refresh_token 有效期为 30 天

• redirect_uri 必须与管理后台配置完全一致

• 建议始终传递 state 参数防止 CSRF 攻击
